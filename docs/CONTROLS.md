# Controls

All bindings are rebindable in Settings. Gamepad works everywhere (buttons shown for a standard pad).

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | WASD / Arrow keys | Left stick |
| Jump / Double jump | Space | A |
| Tail Spin | J | X |
| Mega Roar (full Brain Power) | Hold J | Hold X |
| Stomp (in air) | K | B |
| Chomp / Spit | L | Y |
| Talk / Interact | E or Enter | A (near things) |
| Camera orbit | Drag mouse / Q & R keys | Right stick |
| Camera zoom | Z or mouse wheel | Right stick click |
| Recenter camera | C | R3 |
| Ask Digger (hint) | T | X (held, out of combat) |
| Pause | Esc or P | Start |

- Jump height depends on how long you hold Jump — tap for a hop, hold for full height.
- Coyote time and jump buffering are on (you can press jump slightly early or late — Max forgives).
- Swimming arrives with Fraction Falls (World 4).
